A design system for dense software

Basalt is a React 19 component library and a public catalog. It is built for information-rich products: tables, filters, charts, app shells and long sessions. The identity is a Hanbaiyu marble corner tower; the interface is matte, measured and quiet.

Install @nocoo/basalt. Read the catalog at basaltui.com/ui. Application recipes live at /layout and /login.

Matte luminance

Three stacked surfaces — body, island, card — create depth with light instead of chrome borders.

Granular ESM

A light root barrel for everyday controls, plus subpaths for charts and heavy widgets so product bundles stay small.

App chrome included

Rail, header, island, login badge and page heading ship as recipes. The catalog is the working documentation.
