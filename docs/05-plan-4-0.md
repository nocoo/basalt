# 05 · Basalt 4.0 Architecture, Slimming & `nocoo` Fleet Governance Plan

> Status: Proposed Architectural Plan (Target: `@nocoo/basalt@4.0.0`)
> Baseline: `@nocoo/basalt@3.4.2` (commit `99f3c06b`, 2026-11-16)
> Quality Contract: [`AGENTS.md`](../AGENTS.md) (System0 12-slot gates)
> Benchmark Reference: `@cloudflare/kumo` (`v2.18.1`, `https://kumo-ui.com/`)

## 1. Context, Baseline Evidence & Objectives

Basalt drives the UI of a fleet of web applications under the `nocoo` GitHub organization. While the application shell (`AppShell`, `AppHeader`, `Sidebar`, `ContentIsland`, `PageHeader`, `LayerCard`, `ThemeProvider`, `AccentProvider`) has achieved high adoption, an empirical audit across `@nocoo/basalt@3.4.2` and all **136** `nocoo` repositories exposes structural bloat in the library and drift in upstream consumers.

### 1.1 Empirical Baseline (`@nocoo/basalt@3.4.2` & 136 `nocoo` Repositories)

- **Library footprint (`packages/basalt/`)**:
  - **120** catalog entries ([`src/pages/ui/catalog.ts`](../src/pages/ui/catalog.ts)), **131** exported modules (`packages/basalt/ai/registry.json`), **808** public symbols (**422** values, **386** types).
  - **32** runtime `dependencies` (25 `@radix-ui/react-*` packages, `cmdk`, `sonner`, `marked`, `entities`, `class-variance-authority`, `clsx`, `tailwind-merge`) and **7** `peerDependencies` (`react`, `react-dom`, `lucide-react`, `recharts`, `react-day-picker`, `@tanstack/react-table`, `tailwindcss`).
  - **4.4 MB** unpacked distribution footprint (`packages/basalt/dist/` **3.0 MB** + `packages/basalt/ai/` **1.4 MB**).
- **Fleet adoption across `nocoo` (34 package consumers + 2 Generation-0 hand-copied apps)**:
  - **T1 (`v3.3.x`, 22 repos — 21 active + 1 archived)**: 20 repos on `3.3.6` (`ai-arsenal`, `bat`, `bogo`, `echo`, `ellie`, `fundly`, `geekhub`, `giraffe`, `life.ai`, `lyre`, `meowth`, `noheir`, `ocelot`, `otter`, `pi-superagent`, `raven`, `signoff.now`, `surety`, `wooly`, `zhe`), 1 on `3.3.4` (`rhino`), and 1 archived on `3.3.1` (`steed`).

  - **T3 (`v2.x`, 3 archived repos)**: `archy` (`2.2.0`), `kite` (`2.1.8`), `snail` (`2.1.7`).
  - **T4 (Generation-0 hand-copied Basalt, 2 active repos)**: `backy` (`apps/web/src/index.css`) and `dove` (`src/client/styles/globals.css`), both retaining early Basalt HSL token sheets and local `radix-ui` wrappers without installing `@nocoo/basalt`.
  - **T5 (Independent visual/non-SaaS apps, ~15 repos)**: `dotty`, `matrix`, `linie`, `hexly.ai`, `lizheng.dev`, `chamelo`, `coffee`, `mao`, `sleepy`, `zeppelin`, `pokepocket`, `pew-game`, `diorama-journey`, `zoo`, `rio`, `mico`, `one-ip` — intentionally outside Basalt governance.
- **Usage skew across the 33 scanned Basalt workspaces**:
  - Shell & surface chrome dominate: `AppHeader` (33), `AppShell` (33), `Sidebar` (33), `ThemeProvider` (32), `Tooltip` (32), `Button` (31), `PageHeader` (31), `LayerCard` (30), `LinkProvider` (30), `Avatar` (29), `Input` (28), `AccentProvider` (27), `Badge` (26), `Dialog` (26), `ThemeToggle` (26).

Several wrap Basalt controls with conflicting geometry (e.g., `zhe/components/ui/card.tsx` adds `p-6` / 24px over `LayerCard`) or install duplicate `@radix-ui/*` (`ellie`, `firefly`) and `cmdk` (`lyre`, `noheir`, `octo`, `zhe`).
  - **Install & CSS friction**: Every upstream app has to manually install `lucide-react` alongside `@nocoo/basalt` and compute a relative `@source "../node_modules/@nocoo/basalt/dist/..."` path in its stylesheet.

### 1.2 Benchmark & Four Locked Targets (`4.0`)

Benchmarking against `@cloudflare/kumo@2.18.1` highlights three library-design principles: strict SaaS component boundaries (~48 primitives/components + 3 blocks), a single chart-container module rather than two dozen bespoke chart wrappers, and direct primitive passthrough (`./primitives/*`) for escape-hatch composites. Basalt surpasses Kumo on SaaS layout completeness (`AppShell`, `Sidebar`, `AppHeader`, `ContentIsland`, `PageHeader`, `LayerCard`, `ThemeProvider`, `AccentProvider`) and goes one step further on install ergonomics by removing mandatory external icon peer setup.

Four locked architectural objectives for `@nocoo/basalt@4.0.0`:

1. **Centralized UI control**: Upstream projects own only routes, data/viewmodels, and page layout composition; local `components/ui/*` wrapper directories are eliminated.
2. **World-class standalone library purity**: Prune the catalog from **120** entries to **76** high-cohesion controls/surfaces/blocks (plus optional `Icons` / primitives subpaths), removing domain-specific AI/chat widgets, bespoke chart wrappers, and site-only brand artwork.
3. **Zero-friction single-package install (`bun add @nocoo/basalt`)**: Zero required icon or chart peer packages, zero `LucideIcon` prop lock-in, built-in `@nocoo/basalt/icons` subpath, `@nocoo/basalt/primitives/*` passthrough, and self-registering Tailwind v4 `@source` inside `@nocoo/basalt/styles`.
4. **Worst-first upstream governance**: After publishing `4.0.0`, migrate the fleet in strict tier order starting from **T4** (`backy`, `dove`), then **T2** (`3.2.x`), then **T1** (`3.3.x`), and lock in anti-drift guardrails.

## 2. Architectural Design & Locked Decisions

Per repository policy, Basalt `4.0.0` deletes obsolete paths cleanly without compatibility shims, aliases, or migration re-exports.

### 2.1 Full Chart Engine Decoupling (Decision 1 — Option B)

`@nocoo/basalt` drops all visualization-engine coupling and ceases to ship pre-canned Recharts chart types.

- **Remove `recharts` dependency**:
  - Delete `"recharts"` from `packages/basalt/package.json` `peerDependencies` and `peerDependenciesMeta`, and remove `/^recharts($|\/)/` from `packages/basalt/vite.config.ts` `rollupOptions.external`.
  - Remove `"./charts/*"` from `packages/basalt/package.json` `exports`.
- **Promote `StatCard` & `StatGrid` to core components**:
  - Relocate `packages/basalt/src/charts/stat-card.tsx` (and `stat-card.test.tsx`) to `packages/basalt/src/components/stat-card.tsx` (`@nocoo/basalt/components/stat-card`, catalog category `"card"`).
  - Change `StatCard` `icon` prop type from `LucideIcon` to `React.ReactNode` so callers pass any rendered icon element with zero type coupling.
- **Consolidate engine-agnostic chart chrome into `@nocoo/basalt/components/chart`**:
  - Create `packages/basalt/src/components/chart.tsx` (with `chart.test.tsx`), merging the zero-dependency surface, tooltip, legend, and token primitives from `packages/basalt/src/charts/{frame.tsx,tooltip.tsx,legend.tsx,palette.tsx,config.ts,series.ts}`:
    - `ChartFrame`: pure matte container (`ariaLabel`, `children: React.ReactNode`, `className`, `size`, `loading`, `empty`, `legend`, `footer`) that does **not** import `ResponsiveContainer` from `recharts`. Callers compose `<ResponsiveContainer>`, ECharts, or custom SVG inside `<ChartFrame>`.
    - `ChartTooltipContent`, `ChartTooltipRow`, `ChartLegend`.
    - `CHART_COLORS`, `chart`, `chartAxis`, `chartMuted`, `withAlpha`, `CHART_TYPE`, `seriesColor`, `ChartSeriesDescriptor`.
- **Delete `packages/basalt/src/charts/` completely**:
  - Remove all 21 visualization implementations (`area.tsx`, `bar.tsx`, `bullet.tsx`, `chart-colors.tsx`, `charts.tsx`, `custom-chart.tsx`, `date-navigation.tsx`, `donut.tsx`, `funnel.tsx`, `gauge.tsx`, `grouped-bar.tsx`, `heatmap-calendar.tsx`, `heatmap-matrix.tsx`, `item-list.tsx`, `line.tsx`, `radar.tsx`, `sample.ts`, `sankey.tsx`, `slot-bar.tsx`, `sparkline.tsx`, `stacked-bar.tsx`, `timeline.tsx`, `timeseries.tsx`) plus the legacy source files moved into `components/chart.tsx` and `components/stat-card.tsx`, and their unit tests.
  - Remove the planned `"maps"` entry and the `"chart"` category from `src/pages/ui/catalog.ts` and `src/pages/ui/catalog-categories.ts`; place `Chart` and `StatCard` under `"card"` / `"layout"`.
  - Keep Recharts solely as a site-level `devDependency`/`dependency` for the `basaltui.com` showcase pages (`DataPage`, `HealthPage`, `PortfolioPage`), demonstrating `<ChartFrame>` wrapping native Recharts.

### 2.2 Prune AI/Chat Domain Suite & Redundant/Site-Only Controls (Decision 2 — Option A)

Remove domain-specific multi-agent chat widgets and zero-consumer controls so `@nocoo/basalt` stays a pure general-purpose SaaS UI system:

- **Remove 13 AI / Chat / Agent domain components & markdown runtime dependencies**:
  - Delete from `packages/basalt/src/components/`: `approval-card.tsx`, `recommendation-card.tsx`, `context-cards.tsx`, `thinking.tsx`, `prompt-bar.tsx`, `tool-chips.tsx`, `diff-table.tsx` (along with `packages/basalt/src/models/diff-table.ts`), `chat-bubble.tsx`, `chat-composer.tsx`, `chat-header.tsx`, `chat-inbox.tsx`, `chat-markdown.tsx`, `chat-message.tsx`, and `agent-feedback.test.tsx`.
  - Remove `"marked"` and `"entities"` from `packages/basalt/package.json` `dependencies` and `packages/basalt/vite.config.ts` `rollupOptions.external`.
  - Upstream handling: `meowth` (which uses `ChatHeader`, `ChatInbox`, `ChatBubble`, `ChatComposer`) and `pi-superagent` (which uses `ChatMessage`, `ToolChips`, `ChatComposer`) localize these domain widgets into their own `components/chat/` directories during Wave 3 migration (`frogie` is archived and skipped).
- **Remove 8 zero-consumer redundant or site-brand components**:
  - `basalt-mark.tsx` + `packages/basalt/src/assets/brand-mark.ts` (25.6 KB catalog brand artwork) → relocate into the catalog site (`src/components/BasaltMark.tsx`, `src/assets/brand-mark.ts`) so `@nocoo/basalt` ships zero site-specific logo artwork.
  - `battery-meter.tsx` → superseded by `Meter`.
  - `combobox.tsx` → superseded by `Select`, `MultiSelect`, and `Autocomplete` (inline `typeahead-field.tsx` helpers into `autocomplete.tsx` if no other caller remains).
  - `delete-resource.tsx` → superseded by `ConfirmDialog` (used across 13 repos vs 0 for `DeleteResource`).
  - `flow.tsx` → 0 consumers.
  - `menu-bar.tsx` → 0 consumers; remove `@radix-ui/react-menubar` from `packages/basalt/package.json`.
  - `navigation-menu.tsx` → 0 consumers; remove `@radix-ui/react-navigation-menu` from `packages/basalt/package.json`.
  - `pagination.tsx` → 0 consumers; `TablePager` covers table paging.
- **Catalog surface math (`120 → 76`)**:
  - `120` baseline − `24` removed/consolidated chart entries (`25` chart entries minus promoted `stat-card`) + `1` consolidated `chart` entry − `13` AI/chat entries − `8` redundant/site-brand entries = **`76` focused catalog entries**.

### 2.3 Zero-Friction Install, Internalized Chrome Icons & `@nocoo/basalt/icons` (Decision 3 — Option B)

Eliminate the need for upstream repos to install and track `lucide-react` separately while preserving minimal client bundle output:

- **Internalize all fixed UI chrome icons (`packages/basalt/src/utils/internal-icons.tsx`)**:
  - Replace all `import { ... } from "lucide-react"` inside `packages/basalt/src/` (`app-header.tsx`, `breadcrumbs.tsx`, `chat` removal notwithstanding, `checkbox.tsx`, `code.tsx`, `collapsible.tsx`, `command-palette.tsx`, `date-picker.tsx`, `editable-nav-item.tsx`, `file-dropzone.tsx`, `icon-picker.tsx` search/check/chevron chrome, `pagination` removed, `radio.tsx`, `responsive-master-detail.tsx`, `section-rule.tsx`, `select.tsx`, `sensitive-input.tsx`, `sidebar.tsx`, `table.tsx`, `tag-color-picker.tsx`, `theme-toggle.tsx`, `toast.tsx`, `upload-queue.tsx`, etc.) with small, stroke-consistent inline SVG components (~26 icons total, ~3 KB uncompressed).
  - Normalize every icon prop on components (`Button`, `AppHeader`, `SidebarItem`, `StatCard`, `Empty`, `Banner`, etc.) to `React.ReactNode` so no public type imports from `lucide-react`.
- **Bundle-friendly `@nocoo/basalt/icons` subpath**:
  - Move `"lucide-react"` from `peerDependencies` to `packages/basalt/package.json` `dependencies` (pinned caret range matching the workspace baseline, e.g. `"^1.65.0"`), while keeping `"lucide-react"` in `packages/basalt/vite.config.ts` `rollupOptions.external` so consumer bundlers tree-shake unused icons via native ESM.
  - Create `packages/basalt/src/icons.ts` (`export * from "lucide-react";`) and expose `"./icons": { "types": "./dist/icons.d.ts", "import": "./dist/icons.js" }` in `packages/basalt/package.json` `exports`.
  - Result: Minimal upstream apps run only `bun add @nocoo/basalt` and import application icons from `@nocoo/basalt/icons`; standalone consumers that supply their own icon elements pay **0 bytes** for `lucide-react`.

### 2.4 Self-Registering Tailwind v4 `@source` & `@nocoo/basalt/primitives/*`

- **Two-line Tailwind v4 stylesheet setup**:
  - Prepend `@source "../**/*.js";` to `packages/basalt/src/styles/tailwind.css`. When published at `dist/styles/tailwind.css`, Tailwind v4 resolves the relative glob to `dist/**/*.js`, scanning every Basalt component automatically.
  - Upstream apps simplify their CSS entry to:

    ```css
    @import "@nocoo/basalt/styles";
    @import "tailwindcss";
    ```

    No relative `@source "../node_modules/..."` path calculation is required.
- **Headless primitive passthrough (`@nocoo/basalt/primitives/*`)**:
  - Add `packages/basalt/src/primitives/*.ts` re-exporting each retained `@radix-ui/react-*` dependency (`accordion`, `alert-dialog`, `avatar`, `checkbox`, `collapsible`, `context-menu`, `dialog`, `dropdown-menu`, `hover-card`, `label`, `popover`, `progress`, `radio-group`, `scroll-area`, `select`, `separator`, `slider`, `slot`, `switch`, `tabs`, `toggle`, `toggle-group`, `tooltip`) and add `"./primitives/*"` to `packages/basalt/package.json` `exports`.
  - Keeps root bundle lean while guaranteeing upstream apps never install duplicate `@radix-ui/*` versions for rare bespoke composites.

### 5.3 Wave 3 — T1: `v3.3.x` Main Fleet Convergence & Wrapper Eradication (21 Active Repositories)

Targets: `ai-arsenal`, `bat`, `bogo`, `echo`, `ellie`, `fundly`, `geekhub`, `giraffe`, `life.ai`, `lyre`, `meowth`, `noheir`, `ocelot`, `otter`, `pi-superagent`, `raven`, `rhino`, `signoff.now`, `surety`, `wooly`, `zhe` (archived `steed`, `archy`, `kite`, `snail` excluded).
