## 3. Basalt 4.0 Target Architecture & Surface Disposition (`120 → 77`)

Comparing against `@cloudflare/kumo@2.18.1`: Kumo ships ~48 focused controls, 1 chart wrapper (`./components/chart`), and `./primitives/*` passthroughs, excluding business-specific agent widgets. Basalt `4.0.0` matches this discipline while keeping Basalt's proven SaaS shell (`AppShell`, `Sidebar`, `AppHeader`, `ContentIsland`, `PageHeader`, `LayerCard`, `ThemeProvider`, `AccentProvider`) and delivering a single-package install.

Per repository policy, obsolete paths are removed directly without compatibility shims or aliases.

### 3.1 Four Locked Architectural Changes

1. **Full Chart Engine Decoupling (`@nocoo/basalt/components/chart` & `stat-card`)**:
   - Delete `packages/basalt/src/charts/**`, remove `"./charts/*"` from `packages/basalt/package.json` `exports`, remove `"recharts"` from `peerDependencies` / `peerDependenciesMeta`, and drop `recharts` from `packages/basalt/vite.config.ts` externals.
   - Move `stat-card.tsx` to `packages/basalt/src/components/stat-card.tsx` (`@nocoo/basalt/components/stat-card`, category `"card"`), typing `icon?: React.ReactNode`.
   - Consolidate `frame.tsx`, `tooltip.tsx`, `legend.tsx`, `palette.tsx`, `config.ts`, and `series.ts` into `packages/basalt/src/components/chart.tsx` (`@nocoo/basalt/components/chart`, category `"layout"`):
     - `ChartFrame` (`children: React.ReactNode`, `ariaLabel`, `size`, `legend`, `summary`, `dataAlternative`, `accessibilityLayer` — zero `recharts` import; works with Recharts, ECharts, or custom SVG). Loading, empty, and footer states remain application/card-owned.
     - `ChartTooltipContent`, `ChartTooltipRow`, `ChartLegend`, `CHART_COLORS`, `chart`, `chartAxis`, `chartMuted`, `withAlpha`, `CHART_TYPE`, `seriesColor`, `ChartSeriesDescriptor`.
2. **Prune AI/Chat Domain Widgets & Zero-Consumer/Site-Brand Controls (`120 → 77`)**:
   - Delete **13** AI/chat components (`approval-card`, `recommendation-card`, `context-cards`, `thinking`, `prompt-bar`, `tool-chips`, `diff-table` + `models/diff-table.ts`, `chat-bubble`, `chat-composer`, `chat-header`, `chat-inbox`, `chat-markdown`, `chat-message`) and `agent-feedback.test.tsx`. Drop `"marked"` and `"entities"` from `dependencies` and Rollup externals.
   - Delete **8** unused/site-only components (`battery-meter`, `combobox`, `delete-resource`, `flow`, `menu-bar`, `navigation-menu`, `pagination`, `basalt-mark` + `assets/brand-mark.ts`) and drop `@radix-ui/react-menubar` + `@radix-ui/react-navigation-menu`. Move `BasaltMark` + `brand-mark.ts` into catalog site `src/components/` & `src/assets/`.
   - Realized catalog count: **77** entries (`120 → 77`) after the chart consolidation and removal of 13 AI/chat plus 8 unused/site-brand controls.
3. **Zero-Friction Install (`bun add @nocoo/basalt`), Inline Chrome SVGs & `@nocoo/basalt/icons`**:
   - Inline all ~26 fixed UI chrome icons inside `packages/basalt/src/utils/internal-icons.tsx` (~3 KB) and remove every `lucide-react` import from `packages/basalt/src/components/**`. All component icon props accept `React.ReactNode`.
   - Move `"lucide-react"` from `peerDependencies` to `packages/basalt/package.json` `dependencies` (keep external in `vite.config.ts` for ESM tree-shaking) and export `@nocoo/basalt/icons` (`packages/basalt/src/icons.ts` → `export * from "lucide-react";`). Standalone consumers not importing `@nocoo/basalt/icons` pay 0 bytes.
4. **Two-Line Tailwind v4 CSS & Radix Primitives Passthrough**:
   - Prepend `@source "../**/*.js";` to `packages/basalt/src/styles/tailwind.css` so consumers write only `@import "@nocoo/basalt/styles"; @import "tailwindcss";` without relative `node_modules` paths.
   - Export `@nocoo/basalt/primitives/*` (`packages/basalt/src/primitives/*.ts`) re-exporting each retained `@radix-ui/react-*` primitive so upstream apps never install duplicate `@radix-ui/*` packages.

### 6.1 Standard Per-Repository Migration Playbook

Apply this checklist to every repository across `P3.1`–`P3.6`:

1. **Target & Registry Hygiene**: Bump `@nocoo/basalt` to `^3.5.1`; delete `lucide-react`, `@radix-ui/*`, `radix-ui`, `cmdk`, `sonner`, and `tw-animate-css` from `package.json` (`recharts`, `react-day-picker`, `@tanstack/react-table` kept only if used directly). Because the corporate Microsoft feed lags at `3.2.6`, install via `BUN_CONFIG_REGISTRY=https://mirrors.cloud.tencent.com/npm/ bun install`, then strip any injected mirror URLs from `bun.lock` (`rg -c '", "https' bun.lock` must equal `0`) and verify with `--frozen-lockfile`.
2. **Git Branch Sync & Toolchain Pinning**: Before editing, run `git fetch origin` and `git rebase origin/main` if local `main` diverged, preserving both sides' UI fixes. Put the repo's `.mise.toml` / `packageManager` `bun` version (e.g. `1.3.14` / `1.4.4`) ahead on `PATH` for hooks. If `.env.local` in the working tree blocks `pre-push`, push from a clean detached worktree.
3. **2-Line CSS & Chart Token Migration**: Replace manual `@source` lines in the app CSS with `@import "@nocoo/basalt/styles"; @import "tailwindcss";` and delete shadow `--color-background` / `--color-card` / `tokens.css` files. Rewrite any `var(--chart-*)` / `var(--chart-axis)` references in chart helpers to `--basalt-chart-*` / `--basalt-chart-axis` so SVG charts keep candy colors instead of falling back to black.
4. **Icons, Primitives & `components/ui/*` Removal**: Rewrite `lucide-react` imports to `@nocoo/basalt/icons`; rewrite direct Radix imports to `@nocoo/basalt/primitives/*`. Delete all `components/ui/*` shims/forks (moving genuine business-only components out of `components/ui/` if needed) and import Basalt components directly.
5. **Sidebar, `ContentIsland` & Card Shadow Alignment**:
   - Use `SidebarProvider`, `SidebarBrand` (passing `<Link><Image /></Link>` without custom `w-*`/`h-*` sizing classes), `SidebarToggle`, `SidebarIconItem` (with `<span className="sr-only">{label}</span>`), `SidebarUser`, `SidebarDrawer`, and `AppHeaderMenuButton` directly — never keep custom `SIDEBAR_MARK_SLOT_CLASS`, standalone collapse buttons outside `SidebarHeader`, or duplicate collapsed branches.

6. **Brittle E2E Assertions & `osv-scanner` Waivers**: Remove brittle pixel/typography E2E assertions (`260px` sidebar width, `14px`/`22px` sidebar link typography) rather than overriding Basalt defaults (`240px` / `13px`). Check whether `main` has a PR-only ruleset before pushing.
7. **Gates & Atomic Release**: Never pass `--no-verify`; run the repo's System0 gate (`typecheck`, `lint`, tests, build/E2E) and release `z+1` cleanly.
